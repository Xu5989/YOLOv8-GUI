
# 🚀 YOLOv8 面部表情智能监测系统 (GUI)

这是一个基于 AI 视觉技术的面部表情实时监测工具。集成 YOLOv8 深度学习模型，能够自动识别并标注人脸情绪，适用于演示、测试及简单的实时监测场景。

---

## 🛠️ 运行准备

1. **系统环境**：Windows 11 64位。
2. **硬件要求**：
   - 建议具备摄像头（用于实时检测功能）。
   - 确保 `best.pt` 模型文件与 `app.py` 处于同一文件夹下。
3. **权限说明**：首次运行摄像头功能时，若弹出防火墙或摄像头访问请求，请选择“允许”。

---

## 📖 使用指南

### 1. 启动程序
双击运行 。界面会自动适配系统的深色或浅色主题。

### 2. 核心功能操作
| 功能模块 | 操作说明 |
| :--- | :--- |
| **📂 图片检测** | 点击按钮选择本地图片，系统将瞬间完成识别并显示结果。 |
| **🎞️ 视频检测** | 支持常见视频格式（MP4/AVI等），点击后可实时观看 AI 对视频内容的逐帧分析。 |
| **📷 实时监控** | 调用本机摄像头，开启实时表情追踪模式。 |
| **📸 抓拍暂存** | 在任何检测模式下，点击此按钮可将当前识别画面保存到左侧的“暂存记录”中。 |
| **🚫 停止控制** | 点击后将释放摄像头或停止视频播放，回到待机状态。 |

### 3. 结果查看
- **主屏幕**：实时显示识别框及表情标签（如：Happy, Sad, Neutral 等）。
- **左侧画廊**：所有抓拍的瞬间会以缩略图形式排在左侧侧边栏，方便快速对比。
